# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/mayankdhingra02/engineeringfoundry.dev/security/advisories/new). Do not include credentials, personal data, exploit details, or other sensitive material in a public issue or discussion.

Include the affected area, reproduction conditions, potential impact, and any safe supporting evidence. The maintainer will review reports as capacity permits; this project does not promise a specific acknowledgement or remediation time.

For ordinary defects that do not have security or privacy impact, use the repository's public issue tracker.
